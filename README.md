# 💫 About Me:

I am a Diploma student in Computer Engineering at Vidyalankar Polytechnic, with a strong foundation in programming and software development. I have hands-on experience in C, C++, Java, Python, DBMS, and Data Communication & Networking, along with web development using HTML, CSS, and modern JavaScript frameworks.
I work with technologies like Node.js, React, and backend frameworks, and have experience using tools such as Git, Docker, and cloud platforms. I also have knowledge of UI/UX design using Figma and development environments like Android Studio and Linux.
I am deeply passionate about game development and interactive storytelling. I have developed pixel art characters, built visual novels with mini-games, and implemented inventory systems and RPG mechanics using Ren’Py and Pygame. Currently, I am exploring Godot Engine, focusing on 2D/3D game development, GDScript, and basic C# integration.
Alongside development, I explore fields like Artificial Intelligence, Machine Learning, Generative AI, Prompt Engineering, IoT, Ethical Hacking, and Data Science. I also work with tools such as NumPy, Matplotlib, and PyTorch for learning AI concepts.
I enjoy animation, video editing, and digital art, which helps me create engaging and visually rich user experiences.
I am focused on continuous learning, building real-world projects, and creating innovative solutions that combine technical skills with creativity.
